# نظام إدارة حضور وغياب الطلاب بالكارنيه الذكي (Attendance QR)
### كنيسة مارمينا العجايبي بكوم المحرص — إعداد خدام

نظام ويب متكامل وفائق السرعة والأمان مصمم خصيصاً لإدارة ومتابعة حضور وغياب طلاب الاجتماعات ومدارس الأحد بالكنيسة على مدار **جميع أيام الأسبوع السبعة** ولسنوات قادمة، باستخدام تقنية مسح الـ **QR Code** و **الباركود** المطبوع على الكارنيهات الفعلية.

---

## 🌟 مميزات النظام الأساسية

### 1. ⚡ أداء فوري خارق (Instant Local-First Architecture - 0ms):
- حفظ الطلاب وتسجيل الحضور يتم فورياً في الذاكرة والمتصفح في **أقل من 8 مللي ثانية (0.007 ثانية)** بدون أي تعطيل أو انتظار للإنترنت.
- مزامنة سحابية صامتة وتلقائية مع **Google Cloud Firestore** في الخلفية.

### 2. 📅 دعم تسجيل الحضور لجميع أيام الأسبوع السبعة (7-Day Attendance Matrix):
- تسجيل الحضور المستقل لكل يوم: **السبت، الأحد، الإثنين، الثلاثاء، الأربعاء، الخميس، والجمعة**.
- إمكانية تسجيل أجزاء اليوم المنفردة أو تسجيل اليوم كاملاً بلمسة واحدة.
- تقويم يغطي سنوات سابقة وسنوات قادمة متعددة.

### 3. 📷 ماسح كاميرا فائق الحساسية ومتعدد الصيغ (Multi-Format Barcode & QR Scanner):
- يدعم قراءة كافة أنواع الكارنيهات: `QR Code`، `Code 128`، `Code 39`، `EAN-13`، `DataMatrix`.
- قراءة فورية بمعدل **25 إطاراً بالثانية (25 FPS)** مع إشارات صوتية (Beep) واهتزازات تفاعلية.
- إمكانية التبديل بين الكاميرا الخلفية والأمامية مع صندوق فحص ديناميكي متجاوب.

### 4. 🛡️ منظومة حماية وأمان متكاملة (Enterprise Security Suite):
- **حماية ضد هجمات XSS**: تنظيف وتعقيم كافة المدخلات والمخرجات عبر دالة `sanitizeInput` و `escapeHTML`.
- **ترويسات أمان HTTP قوية**: تطبيق `Content-Security-Policy`، `X-Frame-Options: DENY`، `X-Content-Type-Options: nosniff`.
- **منع التكرار والمسح المزدوج (Scan Cooldown)**: حماية ذكية تمنع قراءة الكارنيه لنفس الطالب مرتين خلال ثوانٍ.
- **حماية ضد التخمين والقوة الغاشمة (Brute-Force Protection)**: قفل المحاولات لمدة 15 دقيقة بعد 5 محاولات دخول خاطئة.
- **قفل الشاشة التلقائي عند الخمول (Inactivity Auto-Lock)**: قفل النظام آلياً بعد 15 دقيقة لحماية البيانات.

### 5. 📄 تصدير تقارير Microsoft Word منسقة (.doc):
- **تقرير الطالب الفردي**: يشمل إحصائيات الحضور التفصيلية ونسبتها وجدول حضور الأسبوع بالهوية الكنسية الرسمية.
- **تقرير مصفوفة الأسبوع الشامل**: جدول أسبوعي متكامل لجميع الطلاب على مدار أيام الأسبوع السبعة، وإحصائيات الحضور والغياب الإجمالية ونسبة الالتزام.

### 6. 📊 لوحة تحكم ذكية ورسوم بيانية (Dashboard & Analytics):
- رسوم بيانية تفاعلية لمعدل الحضور اليومي وتوزيع الطلاب حسب المراحل.
- شريط بث مباشر لآخر عمليات تسجيل الحضور لحظة بلحظة.
- كروت إحصائيات دقيقة ومحدثة فورياً.

```text
d:/ويب 1/
├── index.html                   # موجه الدخول والتحقق من الجلسة
├── login.html                   # صفحة تسجيل دخول الخدام والمسؤولين المحمية
├── dashboard.html               # لوحة التحكم والإحصائيات والرسوم البيانية
├── students.html                # دليل الطلاب وإضافة وتعديل وربط الكارنيهات
├── student.html                 # الملف الشخصي للطالب وسجل الحضور وتصدير تقريره
├── attendance.html              # ماسح الحضور السريع بالكاميرا لجميع أيام الأسبوع
├── reports.html                 # مصفوفة الحضور الشاملة وتصدير التقارير لـ Word
├── settings.html                # إعدادات المواعيد ومحرك الغياب وسجل الأنشطة
├── server.js                    # سيرفر Express المزود بترويسات الأمان الصارمة
│
├── css/
│   ├── style.css                # نظام التصميم الأساسي، الخطوط، الألوان، النوافذ والإشعارات
│   ├── dashboard.css            # أنماط القائمة الجانبية، الجداول، البطاقات والماسح
│   └── responsive.css           # التوافق التام مع شاشات الهواتف والتابلت
│
├── js/
│   ├── firebase-config.js       # إعدادات Firebase والاتصال والتخزين المحلي فائق السرعة
│   ├── auth.js                  # نظام حماية الصفحات وإدارة جلسات الدخول
│   ├── security.js              # مكتبة الحماية ضد XSS، التحقق، ومعدل التكرار
│   ├── students.js              # إدارة الطلاب والبحث السريع والتحقق من تفرد الأكواد
│   ├── attendance.js            # تسجيل ومصفوفة حضور الأيام السبعة والتعديل اليدوي

│
├── manifest.json                # ملف تعريف تطبيق الويب التقدمي (PWA)
├── service-worker.js            # مشغل التخزين المؤقت والعمل دون اتصال

├── firebase.json                # إعدادات الاستضافة ونشر المشروع
└── README.md                    # دليل التشغيل والتوثيق الشامل
```
