# نظام إدارة حضور وغياب الطلاب الذكي بالكارنيه (Attendance QR)
### كنيسة مارمينا العجايبي بكوم المحرص — إعداد خدام

نظام ويب متكامل وفائق السرعة والأمان مصمم خصيصاً لإدارة ومتابعة حضور وغياب طلاب الاجتماعات ومدارس الأحد بالكنيسة على مدار **جميع أيام الأسبوع السبعة** باستخدام تقنية مسح الـ **QR Code** و **الباركود** المطبوع على الكارنيهات، مع الربط السحابي المباشر عبر **Firebase Cloud Firestore**.

---

## 🌟 مميزات النظام الأساسية

### 1. ⚡ ربط سحابي مباشر وفوري (Firebase Cloud Firestore):
- متصل بسحابة Google Firebase (مشروع `k-ilo-eb1f2`) لمزامنة البيانات لحظياً بين كافة أجهزة الخدام (الهواتف، أجهزة اللاب توب، والتابلت).
- عند تسجيل أو تعديل أي طالب أو تسجيل حضور من أي هاتف، يظهر التحديث فورياً على باقي الأجهزة.

### 2. 🎓 تقسيم الطلاب إلى المراحل الدراسية السبع (7 Stages):
1. سنة سادسة
2. أولى إعدادي
3. تانية إعدادي
4. تمهيدي
5. أولى ثانوي
6. تانية ثانوي
7. خريجين
- مع دعم إضافة مرحلة مخصصة يدوياً حسب الحاجة وفلاتر سريعة حسب المرحلة.

### 3. 📷 ماسح كارنيهات ذكي بالكاميرا واستخراج الاسم آلياً:
- **استخراج الاسم التلقائي**: بمجرد توجيه الكاميرا للكارنيه، يقرأ النظام الكود أو الاسم أو الـ QR ويستخرج اسم الطالب ومرحلته تلقائياً.
- **التعريب التلقائي للأسماء (Transliteration)**: تحويل الأسماء المكتوبة بالإنجليزية أو الفرانكو مثل `Mina Siryani` إلى العربية `مينا سرياني` فورياً.
- **دعم مزدوج للكاميرا**:
  - فتح كاميرا الفيديو الحية المباشرة (باختيار الكاميرا المناسبة تلقائياً سواء أمامية أو خلفية).
  - زر التقاط / رفع صورة الكارنيه كحل بديل فائق المرونة.
- **منع التكرار**: تنبيه فوري في حال كان الطالب مسجلاً مسبقاً لمنع تكرار القيود.

### 4. 📅 تسجيل الحضور لجميع أيام الأسبوع السبعة (7-Day Attendance Matrix):
- تسجيل الحضور لكل يوم: **السبت، الأحد، الإثنين، الثلاثاء، الأربعاء، الخميس، والجمعة**.
- تسجيل أجزاء اليوم المنفردة (صلاة، قداس، محاضرة، نوتة روحية، ماراثون) أو تسجيل اليوم كاملاً بنقرة واحدة.

### 5. 📄 تصدير تقارير Microsoft Word منسقة (.doc):
- **تقرير الطالب الفردي**: يشمل إحصائيات الحضور التفصيلية ونسبتها وجدول حضور الأسبوع بالهوية الكنسية الرسمية.
- **تقرير مصفوفة الأسبوع الشامل**: جدول أسبوعي متكامل لجميع الطلاب على مدار الأيام السبعة، مع نسب الالتزام وإحصائيات الحضور والغياب.

### 6. 📊 لوحة تحكم ذكية ورسوم بيانية (Dashboard & Analytics):
- رسوم بيانية تفاعلية باستخدام Chart.js لمعدل الحضور اليومي وتوزيع الطلاب حسب المراحل.
- شريط بث مباشر لآخر عمليات تسجيل الحضور لحظة بلحظة.
- كروت إحصائيات دقيقة وفورية.

## 📁 هيكلية ملفات المشروع (File Architecture)

```text
├── index.html                   # موجه الدخول والتحقق من الجلسة
├── login.html                   # صفحة تسجيل دخول الخدام والمسؤولين المحمية
├── dashboard.html               # لوحة التحكم والإحصائيات والرسوم البيانية
├── students.html                # دليل الطلاب وإضافة وتعديل ومسح الكارنيهات
├── student.html                 # الملف الشخصي للطالب وسجل الحضور والتقرير
├── attendance.html              # ماسح الحضور السريع بالكاميرا لجميع أيام الأسبوع
├── reports.html                 # مصفوفة الحضور الشاملة وتصدير التقارير لـ Word
├── settings.html                # إعدادات المواعيد ومحرك الغياب وسجل الأنشطة
├── server.js                    # خادم محلي مدمج مع دعم المزامنة والترويسات
├── manifest.json                # إعدادات تطبيق الويب التقدمي PWA
├── firestore.rules              # قواعد أمان Cloud Firestore
├── firebase.json                # إعدادات استضافة Firebase Hosting
├── تشغيل_النظام_فورا.bat         # ملف تشغيل النظام محلياً بنقرة واحدة
├── تسجيل_الدخول_في_Firebase.bat   # تسجيل الدخول وتفعيل قواعد Firebase
└── نشر_الموقع_علي_Firebase.bat     # نشر وتحديث الموقع أونلاين على السحابة
```

## 🚀 كيفية التشغيل والرفع

### 1. التشغيل المحلي بنقرة واحدة:
- اضغط ضغطاً مزدوجاً على ملف: **`تشغيل_النظام_فورا.bat`**
- سيبدأ الخادم المحلي ويفتح النظام فوراً في متصفحك على: `http://localhost:3000/dashboard.html`.

### 2. الرفع والتحديث على GitHub:
```bash
git add .
git commit -m "Update Church Attendance QR System with Cloud Firestore & Card Scanner"
git push origin main
```

### 3. النشر على Firebase Hosting:
- اضغط على ملف **`نشر_الموقع_علي_Firebase.bat`** أو نفذ الأمر:
```bash
npx firebase deploy --only hosting,firestore --project k-ilo-eb1f2
```
